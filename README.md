# Encaixxe

Sistema de catálogo e gerenciamento de produtos desenvolvido em ASP.NET Core MVC e Web API para comercialização de produtos organizadores e utilidades domésticas.

## Funcionalidades

### Catálogo Público

* Listagem de produtos
* Busca por nome
* Filtro por categoria
* Filtro por marca
* Paginação
* Produtos em destaque
* Produtos relacionados
* Página de detalhes

### Painel Administrativo

* Login administrativo
* Gerenciamento de produtos
* Gerenciamento de categorias
* Gerenciamento de marcas
* Upload de imagens
* Dashboard com estatísticas
* Mensagens de sucesso e erro

## Tecnologias

* ASP.NET Core MVC
* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* Bootstrap 5
* Bootstrap Icons

## Arquitetura

* Encaixxe.Api
* Encaixxe.Application
* Encaixxe.Domain
* Encaixxe.Infrastructure
* Encaixxe.Web

## Como Executar

1. Configurar a connection string do SQL Server
2. Executar as migrations
3. Configurar o appsettings.Development.json
4. Definir Encaixxe.Api e Encaixxe.Web como projetos de inicialização
5. Executar a solução
